# 🚀 Productivity Tracker - 25 Days React Challenge

A professional task management application built during an intensive 25-day JavaScript & React learning journey.

## ✨ Features
- **Task Management:** Add, delete, and toggle tasks.
- **Analytics Dashboard:** Real-time completion percentage and task stats.
- **Data Persistence:** Uses Custom Hook (`useLocalStorage`) to save data.
- **Global Theme:** Dark/Light mode supported via Context API.
- **Multi-page Navigation:** Smooth routing with React Router.
- **Responsive Design:** Built with Tailwind CSS for all devices.

## 🛠️ Tech Stack
- React.js (Vite)
- Tailwind CSS
- React Router DOM
- Context API (State Management)
